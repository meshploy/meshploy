# Your own Caddy configuration

`caddy/Caddyfile` is generated by `meshploy domain apply` from the base domains
this gateway serves. It is rewritten whenever a domain is added, removed,
verified, or has its DNS mode changed, so anything written there is lost.

Every `*.caddy` file in this directory is imported into that generated config
and is never touched. Put site blocks, snippets and global options you want to
keep here.

```caddyfile
# conf.d/status.caddy
status.example.com {
    respond "ok"
}
```

Run `sudo meshploy domain apply --force` afterwards to reload Caddy: without
`--force` it finds the generated files unchanged and does nothing. Caddy checks
the whole configuration before switching to it, so a mistake here is reported
and the previous configuration keeps serving.
