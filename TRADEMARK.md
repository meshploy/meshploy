# Meshploy trademarks

"Meshploy" and the Meshploy logo are trademarks of Pritthish Nath. The Apache
License, Version 2.0 grants rights to the code, and states plainly that it
grants no rights to a project's trademarks. This page says what is and is not
allowed, so the code stays free to use while the name still means one thing.

## You may, without asking

- Say that your product runs on, integrates with, or is built with Meshploy.
- Use the name to describe an unmodified build of the software, in
  documentation, articles, talks and comparisons.
- Keep the name and marks where they already appear when you redistribute the
  software unmodified.

## Please ask first

- Naming a product, service, company or domain in a way that includes
  "Meshploy", or a name close enough to be mistaken for it.
- Using the logo as the mark of your own product, or in a way that suggests
  Meshploy endorses or maintains what you are shipping.
- Selling a hosted service under the Meshploy name.

## Modified builds

You may modify the software, as the licence allows. A modified build must not
be distributed under the Meshploy name in a way that suggests it is the
official one. Say "based on Meshploy" instead, and keep the attribution the
licence requires.
