## Templates {#templates}

A **template** is a ready-made app, such as a CMS, an analytics tool, a queue or a monitoring stack, deployed in one step. Choose one, fill in the few values it asks for, and it is created in a project as a **stack**: its services, volumes, routes and config files, all visible and editable afterwards.

## Where they come from {#catalog}

The catalog is fetched from Meshploy's public template repository and refreshed regularly. An air-gapped installation can use a local folder of templates instead.

## Terms {#terms}

- **Template** {#template -> templates}: A ready-made app deployed in one step, as a stack you can open and change afterwards.
